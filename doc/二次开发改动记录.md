# 二次开发改动记录（相对上游）

> 记录本 fork（`origin = github.com/clzx8668/AppFlowy`）相对上游 AppFlowy 的每一处改动，
> 用于后续合并上游 Core 修复时快速定位差异。规则见仓库根 `AGENTS.md`。
> 所有改动只在前端适配层，`frontend/rust-lib` 内核零改动。

## 2026-09-23 · 步骤①：本地优先模式（跳过登录 + 隐藏云端入口）

**背景**：上游 0.11 默认连接 AppFlowy Cloud，当前网络下 `appflowy.cloud` 被 Cloudflare 403，
真机启动后卡在登录页无法进入工作区；且产品规划已明确放弃 AppFlowy Cloud、走全本地 + WebDAV 快照同步。

**做法**：新增一个显式开关 `kLocalFirstMode`，集中控制"全本地优先"，其余 4 处只在既有条件分支上收口。

| 文件 | 改动 |
| --- | --- |
| `lib/env/local_first.dart`（新增） | 本地优先开关 `kLocalFirstMode`，是本次唯一"总闸"；置 `false` 即回退到上游行为 |
| `lib/main.dart` | 启动改为 `runAppFlowy(isAnon: kLocalFirstMode)`：匿名模式自动创建/复用本地用户，不请求云 |
| `lib/env/cloud_env.dart` | `AppFlowyCloudSharedEnv.fromEnv()` 在本地优先模式下直接返回 `AuthenticatorType.local` 与空云配置；于是 `isAuthEnabled` / `isAppFlowyCloudEnabled` 均为 false，云同步任务不初始化、账号登录/订阅/协作入口按上游既有条件自动隐藏 |
| `lib/user/presentation/screens/splash_screen.dart` | 未启用云鉴权时不再把移动端强制跳到登录页（上游 `isAuthEnabled \|\| UniversalPlatform.isMobile` 会让本地模式在手机上卡在登录页） |
| `lib/workspace/presentation/settings/widgets/settings_menu.dart` | 未启用云时隐藏"云服务设置"菜单项 |
| `lib/mobile/presentation/home/tab/space_order_bloc.dart` | 未启用云时隐藏移动端 `Shared`（协作/共享）标签页，并让被隐藏的默认标签回退到首个可见标签，避免 `TabController` 初始索引越界 |
| `doc/tools/android-rust-build.sh` | 修复：不再清空 `jniLibs` 目录（会删掉 CMake 放入的 `libc++_shared.so`，导致真机 `dlopen failed: library "libc++_shared.so" not found`），并在缺失时自动从 NDK 补齐 |

**验证**（荣耀 ELZ-AN10，Android 14）：

- 启动日志：`restart AppFlowy: isAnon: true`、`cloud setting: authenticator: AuthenticatorType.local`、
  云配置全空 `{base_url: , ws_base_url: , gotrue_url: ...}`，无任何云请求、零异常；
- 启动耗时从 4.2s 降到 0.8s（少了云相关初始化）；
- 界面：直接进入本地工作空间（空间/最近/收藏），可正常新建与编辑笔记，重装 APK 后本地数据保留；
- 回归：`dart analyze`（改动文件）无告警；`flutter build windows --debug` 通过。

**后续待办**（本步骤遗留）：

1. 桌面端侧边栏「Shared/发布站点/邀请成员」等云协作入口尚未逐一核对隐藏。
2. 移动端首页设置弹窗（`HomePageSettingsPopupMenu`）内的云相关项待核对。
3. 登录/注册路由与页面代码保留未删除（按规约"只隐藏不删除"）。

## 2026-09-23 · 步骤①收尾：清空剩余云端/协作入口

**做法**：仍以 `kLocalFirstMode` 为准，逐屏核对后把仍在显示的云端入口收口；并修掉一个"重启丢模式"的隐患。

| 文件 | 改动 |
| --- | --- |
| `lib/startup/startup.dart` | `runAppFlowy()` 的 `isAnon` 默认值改为 `kLocalFirstMode`。此前内部重启入口（登出、切换数据目录、错误页重试等 18 处调用）用的是默认 `false`，会退回非本地模式并落到欢迎/登录流程 |
| `lib/mobile/presentation/home/mobile_home_setting_page.dart` | 隐藏 `CloudSettingGroup`（Cloud settings / Cloud server）；隐藏 `UserSessionSettingGroup`（退出登录、第三方登录）——本地模式没有账号概念 |
| `lib/mobile/presentation/setting/personal_info/personal_info_setting_group.dart` | 隐藏「You're in local mode + Login to AppFlowy Cloud」按钮 |
| `lib/mobile/presentation/setting/launch_settings_page.dart` | 隐藏 `SelfHostSettingGroup`（自建服务端配置） |
| `lib/workspace/presentation/home/menu/sidebar/footer/sidebar_footer.dart` | 桌面侧边栏隐藏「模板」（指向 appflowy.com/templates）入口 |

**核对结论（逐项）**：

| 位置 | 结论 |
| --- | --- |
| 移动端首页右上「⋯」菜单 | 成员/邀请入口本来就由 `workspaceType == ServerW` 控制，本地模式已不显示（截图确认只剩 设置/回收站/帮助/支持） |
| 移动端设置页 | 已无 Cloud settings、无 Login to AppFlowy Cloud（真机截图确认） |
| 移动端首页标签栏 | `Shared` 标签页已隐藏（上一步） |
| 桌面侧边栏 | 本地模式下走 `SidebarFolder`（非空间/协作布局），无 Shared 分区、无工作空间切换器、无升级提示；模板入口已隐藏 |
| 桌面设置弹窗 | 云服务设置菜单项隐藏（上一步）；账号页登录区由 `isAuthEnabled` 控制，本地模式不显示 |
| 文档页「分享」按钮 | **保留**：本地模式下 `enablePublish == false`，该菜单只剩「导出为」等本地功能（改名/隐藏与否待定） |
| 未处理（非协作类，待确认） | 移动端设置页「支持」组（Discord/上报问题）、「关于」组（隐私政策/条款）等外部链接；桌面端「获取支持」入口 |

**验证**：

- 真机（荣耀 ELZ-AN10）：重新安装后逐屏截图核对，设置页与首页菜单均无云端/登录入口；应用正常进工作区、可编辑笔记。
- Windows 桌面端：`flutter build windows --debug` 通过；应用数据目录为 `%APPDATA%\io.appflowy\AppFlowy\data_dev`（本地），
  昨日云模式用的是 `data_dev_beta.appflowy.cloud`，说明桌面端也已切到本地模式；Rust 日志中无 403/登录相关记录。
